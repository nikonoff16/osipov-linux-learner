## 1. Service для мониторинга лога

Создадим сервис, который будет проверять лог-файл на наличие ключевого слова каждые 30 секунд.

Создаем файл конфигурации `touch /etc/default/log-monitor` и наполняем следующим содержимым:

```bash
LOG_FILE="/var/log/syslog"
KEYWORD="error"
```

Создаем скрипт сервиса `touch /usr/local/bin/log-monitor.py` и помещаем туда его текст:
```bash
#!/usr/bin/env python3

import time
import os
import re
import sys

def load_config(config_path="/etc/default/log-monitor"):
    config = {}
    try:
        with open(config_path, 'r') as f:
            for line in f:
                line = line.strip()
                if not line or line.startswith('#'):
                    continue
                if '=' in line:
                    key, value = line.split('=', 1)
                    config[key.strip()] = value.strip().strip('"\'')
    except Exception as e:
        print(f"Error loading config: {e}", file=sys.stderr)
        sys.exit(1)
    
    return config

def monitor_log(log_file, keyword):
    try:
        # Check if log file exists
        if not os.path.exists(log_file):
            print(f"Error: Log file {log_file} does not exist", file=sys.stderr)
            return False
        
        # Check last few lines for the keyword
        with open(log_file, 'r') as f:
            # Read the last 100 lines to avoid processing the entire file
            lines = f.readlines()[-100:]
            for line in lines:
                if re.search(keyword, line, re.IGNORECASE):
                    print(f"Keyword '{keyword}' found in {log_file} at {time.strftime('%Y-%m-%d %H:%M:%S')}")
                    print(f"Matching line: {line.strip()}")
                    return True
    except Exception as e:
        print(f"Error monitoring log: {e}", file=sys.stderr)
    
    return False

def main():
    # Load configuration
    config = load_config()
    
    log_file = config.get('LOG_FILE')
    keyword = config.get('KEYWORD')
    
    if not log_file or not keyword:
        print("Error: LOG_FILE or KEYWORD not set in config", file=sys.stderr)
        sys.exit(1)
    
    print(f"Starting log monitor for '{keyword}' in {log_file}", file=sys.stderr)
    
    # Main loop
    while True:
        monitor_log(log_file, keyword)
        time.sleep(30)

if __name__ == "__main__":
    main()
```

Сделаем скрипт исполняемым:
```bash
chmod +x /usr/local/bin/log-monitor.py
```

Создаем Unit-файл сервиса `touch /etc/systemd/system/log-monitor.service`:
```ini
[Unit]
Description=Log Monitor Service
After=syslog.target network.target

[Service]
Type=simple
ExecStart=/usr/local/bin/log-monitor.py
Restart=on-failure
User=root
Group=root
StandardOutput=syslog
StandardError=syslog

[Install]
WantedBy=multi-user.target
```

Команды для активации сервиса:
```bash
systemctl daemon-reload
systemctl enable log-monitor.service
systemctl start log-monitor.service
```

Проверяем:

## 2. Установка spawn-fcgi и создание unit-файла

Установка spawn-fcgi:
```bash
apt-get install -y spawn-fcgi php-cgi
```

Создаем unit-файл `touch /etc/systemd/system/spawn-fcgi.service`:
```ini
[Unit]
Description=Spawn-fcgi service
After=network.target

[Service]
Type=forking
PIDFile=/var/run/spawn-fcgi.pid
ExecStart=/usr/bin/spawn-fcgi -a 127.0.0.1 -p 9000 -u www-data -g www-data -P /var/run/spawn-fcgi.pid -- /usr/bin/php-cgi
ExecStop=/bin/kill -15 $MAINPID
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

Активируем сервис:
```bash
systemctl daemon-reload
systemctl enable spawn-fcgi.service
systemctl start spawn-fcgi.service
```

Проверяем:

## 3. Доработка unit-файла Nginx для нескольких инстансов

Создаем модифицированный unit-файл `touch /etc/systemd/system/nginx@.service`:
```ini
[Unit]
Description=Nginx Instance - %i
After=network.target

[Service]
Type=forking
PIDFile=/run/nginx-%i.pid
ExecStartPre=/bin/sh -c "mkdir -p /run/nginx && touch /run/nginx-%i.pid && chown www-data:www-data /run/nginx-%i.pid"
ExecStartPre=/usr/sbin/nginx -t -c /etc/nginx/%i.conf
ExecStart=/usr/sbin/nginx -c /etc/nginx/%i.conf
ExecReload=/bin/kill -s HUP $MAINPID
ExecStop=/bin/kill -s TERM $MAINPID
TimeoutStartSec=10
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

### Настройка и запуск инстансов:
Создаем конфигурационные файлы для каждого инстанса:
   - `touch /etc/nginx/instance1.conf`
   - `touch /etc/nginx/instance2.conf`
```Instance 1
pid /run/nginx-instance1.pid;
user www-data;

events {
    worker_connections 1024;
}

http {
    server {
        listen 8080;
        server_name localhost;
        location / {
            return 200 "This is instance1!\n";
        }
    }
}
```

```Instance 2
pid /run/nginx-instance2.pid;
user www-data;
events {
    worker_connections 1024;
}

http {
    server {
        listen 8081;
        server_name localhost;
        location / {
            return 200 "This is instance2!\n";
        }
    }
}
```

Проверяем, не заняты ли выбранные порты:
```Shell
ss -tulnp | grep ':8080'
ss -tulnp | grep ':8081'
```
Создаем необходимые для работы инстансов директории:
```Shell
mkdir -p /run/nginx
chown www-data:www-data /run/nginx
```
Запускаем инстансы:
```bash
systemctl start nginx@instance1
systemctl start nginx@instance2
```
Включаем автозапуск:
```bash
systemctl enable nginx@instance1
systemctl enable nginx@instance2
```
