# Руководство по обновлению ядра Linux на Ubuntu 24.04

## Введение
Это руководство описывает процесс обновления ядра Linux до более новой версии на сервере под управлением Ubuntu 24.04 LTS.


## 1. Проверка текущей версии ядра
Перед обновлением проверяю версию ядра, установленную в моей виртуалке, командой:
```bash
uname -r
```
Получаю следующий результат:
```bash
osipov@server:~$ uname -r
6.8.0-60-generic
```
## 2.  Установка mainline ядра
Далее добавляю репозиторий утилиты mainline, устанавливаю ее, и смотрю, какие версии ядра мне доступны:

```bash
sudo add-apt-repository ppa:cappelikan/ppa
sudo apt update
sudo apt install mainline 
mainline list
```
Получаю такой результат:
```bash
osipov@server:~$ mainline list
mainline 1.4.13
Updating Kernels...
----------------------------------------------------------------
Available Kernels
----------------------------------------------------------------
6.15
6.14.8
...
```

Далее выбираю себе версию ядра 6.10.14 (случайную, выше текущей версии, но не сильно новую, максимально пропатченную). Предварительно устанавливаю себе программу **pkexec**, т.к. без нее mainline даже под судо и рутом не выполняется корректно:
```bash
sudo apt install policykit-1
sudo mainline install 6.10.14
```
Проверяю доступные версии ядра после установки:
```bash
osipov@server:~$ ls /boot/vmlinuz-*
/boot/vmlinuz-6.10.14-061014-generic  /boot/vmlinuz-6.8.0-60-generic
```

## 3. Обновление GRUB
После установки нового ядра обновляю груб (хотя судя по логам установки ядра, эта процедура была проведена, просто на всякий случай) и перезапускаю хост
```bash
sudo update-grub
sudo reboot
```

## 4. Проверка новой версии ядра
После перезагрузки проверяю версию ядра:
```bash
osipov@server:~$ uname -r
6.10.14-061014-generic
```
